# 衛教文章寫作規範

> **先讀全域 `human-voice`**(`~/.claude/skills/human-voice/SKILL.md`)。
> 那份管通用的中文去 AI 腔、破折號字形(一律「──」,教育部標準)、
> 以及張醫師 2026-09-02 修訂裡**任何中文文章都適用**的四條句法
> (條件前置、關聯詞寫完整、名詞補完整、代名詞寫回名詞)。
> 本檔只放**這個網站才有**的東西。兩份衝突時,醫療紅線(第五章)以本檔為準,
> 其餘以全域為準。
>
> 2026-10-04 前本檔也叫 `human-voice`,跟全域同名;改名是為了兩份都讀得到。

這份規範服務兩個同時存在、方向相反的需求：

- **GEO** 要結構：結論先行、數值精確、表格化，好讓搜尋引擎和 AI 能整段擷取。
- **人味** 要溫度：這是一位執業醫師的個人網站，不是衛福部的衛教手冊。

解法是分層，不是折衷：**骨架照結構走，血肉用門診口吻寫。**
速答框、對照表、警訊清單保持冷靜精確；中間的敘述段落放開來寫。

## 一、文章骨架（每篇都要有）

| 區塊 | 寫法 | 任務 |
|---|---|---|
| 標題 | 病人真的會打進搜尋框的問句 | 對上字面 |
| 醫師速答 | 開頭 1–2 句給結論，含關鍵數值 | AI 優先擷取段落前 50–100 字 |
| 為什麼會這樣 | 機轉與成因，門診口吻 | 給人讀的，建立信任 |
| 決策對照表 | 數值分級 × 判讀 × 處置 | AI 最容易整段搬走的形式 |
| 你可以怎麼做 | 具體到可執行 | 精確數字勝過程度副詞 |
| 什麼情況要就醫 | 紅旗警訊與時間閾值 | 醫療倫理必要，也最常被引用 |
| 參考依據 | 指引名稱與版本 | 權威度錨點 |
| 作者卡 + 更新日期 | 姓名、專科、任職 | 把權威度綁回醫師實體 |

標題用病人的話，不用教科書的話：

- ✗ 論慢性腎臟病之臨床表徵與分期
- ✓ eGFR 55 是第幾期？還會不會好？

## 二、八條寫作規則

**1. 先給答案，再講原理。**
搜尋進來的人是焦慮的。第一段就回答問題。不要用「腎臟是人體重要的排毒器官」暖場，那句話對已經在擔心自己腎臟的人來說是浪費時間。

**2. 刪掉萬用形容詞。**
「全面」「深入」「重要的」「有效地」「不僅⋯⋯更」「隨著⋯⋯的提升」。刪掉之後句子通常更好讀。如果刪掉之後句子沒有變短，代表那個詞本來就沒在做事。

**3. 用診間真的會講的句子。**
「這個數字不用太緊張，但三個月要再驗一次」比任何標準衛教語句都可信。寫的時候可以先想：如果病人現在坐在你對面，你會怎麼說？

**4. 具體數字取代程度副詞。**
不要寫「大幅降低風險」，寫實際的區間或百分比。不要寫「少吃鹽」，寫「每日鈉攝取低於 2,000 毫克，大約是一茶匙鹽」。這同時也是 GEO 要的東西，一石二鳥。

**5. 句長要不平均。**
AI 寫的句子長度太整齊，這是最容易被察覺的痕跡。刻意讓長句和短句交錯。該斷的地方就斷。

**6. 條列只留給真正並列的東西。**
不是每段都要變成三點式條列。敘述性內容用段落寫。決策對照、警訊清單、藥物分類這種真的並列的才用條列或表格。

**7. 敢說不確定。**
「這部分目前證據還不一致」「臨床上會依個人狀況調整」比假裝什麼都有標準答案更專業，也更符合醫療倫理。

**8. 留下個人視角。**
適度出現「我通常會建議」「門診常遇到的狀況是」「這題我被問過很多次」。這是個人品牌網站和衛教手冊的差別，也是 AI 最難模仿的部分。

## 三、張醫師句法修訂：本站專屬的部分

張醫師 2026-09-02 修訂第一版六篇文章，整理成六條規範後套用，共改 94 處（commit `8986244`）。
其中四條是通用的中文句法，已移到全域 `human-voice` §2.5（附原句對照），這裡不重複：
條件與範圍前置、「不是 X，而是 Y」補回「而是」、名詞補完整、段落開頭代名詞寫回名詞。

留在本檔的是跟醫師口吻、醫療轉述有關的規則，第 1–3 條來自 09-02，後面依修訂日期往下編號。出處要分清楚：第 1、2 條來自醫師給的改寫實例；
第 3 條（破折號）和移走的代名詞那條**沒有可追溯的原始回饋**，是助手整理時推導擴寫的
（見全域 `human-voice` §7）。

**1. 指示句用書面語，不要用過度口語或帶攻擊性的說法。**

「下手」改成「著手處理」；「不知道換過」改成「不知道家裡的鹽已經換過」。
第一人稱敘述裡的口語（「湯喝得很豪邁」）可以留，那是門診口吻；
但出現在指示句就要換回書面語。

**2. 轉述指引用「提到…建議…」，不要直接寫成「指引建議你」。**

- ✗ KDIGO 2024 指引建議有蛋白尿的慢性腎臟病患者使用 SGLT2 抑制劑，不論有沒有糖尿病。
- ✓ KDIGO 2024 指引提到，不論有沒有糖尿病，皆建議有蛋白尿的慢性腎臟病患者使用 SGLT2 抑制劑。

「提到」保留了轉述的距離，也守住「這是指引的一般性建議、不是對這位讀者的個別醫囑」
這條界線。

**3. 破折號不要當萬用轉折。**（助手推導，無原始回饋）

這是第一版最明顯的 AI 痕跡：一段話裡出現三四個破折號，全部拿來接補充說明（第一版 49 個，修訂後剩 2 個）。
改成句號、分號、冒號，或補上「因為」「也就是」「這就是」。
真正該留破折號的只有兩種：擬聲（「呼──呼──」）和真正的插入語。
字形一律用教育部標準的「──」（U+2500 ×2），不用「——」（U+2014 ×2）。

### 2026-10-04 補充（乾體重一文的修訂）

**4. 轉述研究結果用「研究中發現，X，容易 Y」，不要寫「研究上，X 與 Y 有關」。**

- ✗ 研究上，脫水速度超過每小時每公斤 13 毫升，與較高的死亡風險有關。
- ✓ 研究中發現，脫水速度超過每小時每公斤 13 毫升，容易有較高的死亡風險。

「研究上…有關」是論文摘要的翻譯腔，病人讀不出輕重。「研究中發現」交代了出處，
「容易」保留了觀察性研究「相關、不等於因果」的分寸，兩件事一句話就做到。

**5. 不要用「東西」「狀況」這類空泛名詞代替具體的東西。**

- ✗ 心裡懷疑機器是不是把太多東西抽走了。
- ✓ 心裡懷疑機器是不是把太多水分抽走了。

能說出是什麼，就寫出來。這和全域 `human-voice` §2.5 第 3 條（名詞補完整）同一個道理：短不是目的，準確才是。

### 2026-10-08 第二輪修訂：心衰竭文章的 21 處修改

張醫師修訂〈胸好悶，喘不停，我是不是有心臟衰竭？〉初稿，以下四條都有原始回饋。
句內連詞要寫出來（「若…就」「而…」「雖然…但是」）的那條是通用句法，已寫進全域 `human-voice` §2.1 表下說明。

**6. 因果不要寫成必然，用「容易／通常／會」。**

- ✗ 堆在肺裡，就會喘 → ✓ 若堆在肺部，人就容易喘
- ✗ 比較指向心衰竭的是…走一小段路就喘 → ✓ 通常指向心衰竭的是…走一小段路就容易喘
- ✗ 心臟負擔變重 → ✓ 心臟負擔會變重

症狀和機轉描述的是多數人的傾向，不是每個人都會發生。

**7. 比喻和口語動詞換成臨床用語。**

- 主角 → 主要表現；拿掉（水）→ 脫掉；（身體的）需要 → 需求；拿到的血也少 → 拿到的血變少
- 主詞補完整：心臟本身不一定變差 → 不一定是心臟本身功能變差；血液回不去 → 全身的血液回不去心臟

門診口吻靠「我通常會建議」這類第一人稱，不靠擬人和口語動詞。

**8. 指示句用商量的語氣，並講清楚要避免的是什麼。**

- ✗ 藥要吃滿，不要自己停 → ✓ 藥要吃滿，調藥最好要跟醫師討論
- ✗ 這些反應請回診告訴醫師調整，不要覺得不舒服就自己停掉 → ✓ 有這些反應請提早回診調整藥物，不要覺得不舒服就自己全部停掉
- ✗ 鹽和水，按醫師給的數字 → ✓ 鹽和水量，遵循醫師建議
- ✗ 不要自己下結論 → ✓ 不要自己覺得數字正常就沒問題
- ✗ 證據要講清楚 → ✓ 證據我們還是要先講

「不要自己下結論」太空泛，讀者不知道要避免什麼；要直接寫出那個具體的錯誤做法。

**9. 連到購買頁時，文章裡不重複寫利益揭露。**

點進購買頁就會看到揭露，文中只放站內連結和一句用途說明。非透析主題的文章也不要順手帶入透析的細節（例如瘻管那隻手不要手搖）。

## 四、示範

**修改前**（典型 AI 腔）

> 腎臟是人體重要的排毒器官，慢性腎臟病是一個不容忽視的健康議題。透過全面的飲食控制與規律的生活作息，可以有效地延緩腎功能惡化，維護整體健康。

**修改後**

> 如果你的 eGFR 落在 45 到 59 之間，那是第三期。這個階段大部分人沒有任何感覺，但接下來怎麼做，會決定你十年後在不在洗腎室。門診裡我最常先問的是血壓和止痛藥的使用習慣。這兩件事的影響，比多數人以為的飲食控制還大。

差別在哪：給了具體數值、給了時間尺度、講了一件讀者原本不知道的事、而且聽得出是一個人在說話。

## 五、醫療內容的紅線

**所有臨床數值一律標成待確認。**
寫初稿時，任何檢驗閾值、藥物劑量、分期標準、風險百分比，都用 `<!-- 待醫師確認 -->` 標記，由張醫師逐一核對後才定稿。不要憑印象寫指引數字，也不要從其他 AI 的輸出直接搬。

**每個待確認的數字都要附出處；找不到出處就不要寫數字。**
在 `.tbc` 旁用 HTML 註解寫明來源（指引名稱、版本、表號或頁碼，或 PMID），讓醫師審閱時能直接查證。
實例（2026-10-08）：初稿寫了「體重 3 天內增加超過 2 公斤就聯絡醫師」，醫師問有沒有論文根據。
這個數字在衛教材料裡很常見，但證據等級屬專家共識，而且我沒查到 2021 年 ESC 指引的原文出處，最後改成「短時間增加太多就必須留意」。
**「很常見」不等於「有出處」**；寫不出出處的數字，用質性描述代替。改一處就要全篇 grep，表格、警訊清單、FAQ JSON-LD 都要一起改。

**引用指引要寫版本。**
「根據 KDIGO 2024 臨床指引」比「根據國際指引」有用得多，對讀者、對 AI 都是。但版本本身也要確認過。

**不要寫成診所導購。**
作者卡註明任職地點是必要的信任訊號。但文章通篇為特定機構鋪陳設備優勢，性質就從衛教變成招攬，在醫療法下有風險。「病人可以怎麼評估洗腎室」可以寫；「我們的洗腎室有什麼設備」不要寫。

**每個數字都要說得出出處。**
交稿時，每一個臨床數值都要能對應到文末某一篇參考文獻。說不出出處的數字，
不要靠「臨床上常用」帶過：去找文獻，找到了照文獻的數字改寫並補上引用；找不到就拿掉。
（2026-10-04：乾體重一文原本寫「不超過乾體重的 3% 到 4%」，查證後改為有 DOPPS 研究支持的 4%。）

**換算出來的數字，把換算過程收進「怎麼算的？」。**
有些數字不是文獻直接給的，而是生理換算的結果（例如「8 公克鹽大約留住 1 公升水」）。
正文只留結論，句尾放一顆「怎麼算的？」按鈕，換算步驟收在可展開的 `.explain` 說明框裡，
並註明「這是換算，不是單一研究的結果」。元件用法見 `articles/_template.html`。

**每篇都要有免責聲明。**
內容僅供參考，實際診療請諮詢您的主治醫師。

## 六、檢查清單

寫完之後逐條看一遍（通用的句法檢查見全域 `human-voice`）：

- [ ] 第一段有沒有直接回答標題的問題
- [ ] 有沒有「全面／深入／有效地／重要的」還活著
- [ ] 有沒有至少一張決策對照表
- [ ] 程度副詞有沒有換成具體數字
- [ ] 連續三段是不是都是條列
- [ ] 有沒有一句話聽得出是醫師本人在講
- [ ] 所有臨床數值有沒有標待確認
- [ ] 有沒有寫「什麼情況要就醫」
- [ ] 有沒有作者卡、更新日期、免責聲明
- [ ] 條件子句有沒有吊在句尾
- [ ] 「不是…是…」有沒有補上「而」
- [ ] 破折號有幾個，是不是拿來當轉折用，字形是不是「──」
- [ ] 段落開頭的代名詞找不找得到指涉對象
- [ ] 轉述指引是不是用「提到…建議…」
- [ ] 轉述研究是不是寫成「研究中發現…容易…」
- [ ] 有沒有「東西」「狀況」可以換成具體名詞
- [ ] 每個數字對不對得到文末的參考文獻；換算出來的有沒有收進「怎麼算的？」
- [ ] 機轉與症狀有沒有寫成必然（「就會喘」→「就容易喘」）
- [ ] 有沒有擬人、比喻或口語動詞（主角、拿掉）沒換成臨床用語
- [ ] 指示句是不是命令語氣、有沒有講出具體要避免的做法
- [ ] 每個待確認數字旁有沒有出處註解
